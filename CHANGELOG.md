# Changelog

What changed in Open3D-SDK, newest first.

## In development

- **First version.** The common files every Open3D repository holds, and three starters a new app's
  repository is made from: a Windows program in Rust, a 3ds Max plug-in in Python and one in C++. Each
  passes its own checks once its codes are made.
- **Who writes where.** The guides say that members read every app and write only in their own and in the
  shared repositories, that a change to another member's app comes from a fork, that tags are made only by
  admins, that a published release cannot change, and that signing the launcher's catalog waits for a
  second member.
- **The common files, tidied.** Their comments no longer name the numbers of the maintainers'
  decisions, and the C++ settings file follows the Open3D style, lines of up to 120.
